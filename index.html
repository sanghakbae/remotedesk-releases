Features

원격인 걸 잊게 되는
원격 데스크톱

화면은 선명하게, 입력은 바로바로. 운영체제가 달라도 평소 쓰던 그대로 손이 갑니다.

맥 ⇄ 윈도우, 단축키까지 맞춰서

맥에서 윈도우를 열면 ⌘C가 Ctrl+C로 갑니다. 같은 운영체제끼리도, 서로 다른 운영체제끼리도 자연스럽게 씁니다. 한/영 전환과 한글 입력도 됩니다.

⌘ C → Ctrl C ⌘ V → Ctrl V ⌘ Z → Ctrl Z 오른쪽 ⌘ → 한/영

아이폰·아이패드에서도

Safari로 주소만 열면 끝. 탭하면 클릭, 길게 누르면 오른쪽 클릭, 두 손가락으로 확대합니다.

최대 60fps

macOS는 ScreenCaptureKit으로 화면을 잡고, 바뀐 부분만 골라 보냅니다. 실제 속도는 네트워크에 따라 다릅니다.

해상도 자동 맞춤

상대 컴퓨터 해상도에 맞춰 창 크기를 잡습니다. 화질은 낮음부터 최고까지 네 단계.

복사·붙여넣기 공유

텍스트, 이미지, 파일까지. 이쪽에서 복사하고 저쪽에서 붙여 넣으세요.

잠들지 않게

공유하는 동안 컴퓨터가 잠자기에 빠지지 않아, 퇴근 후에도 접속이 끊기지 않습니다.

처음부터 끝까지 암호화

비밀번호에서 만든 키로 화면과 입력을 모두 AES-GCM 암호화. 웹 접속은 HTTPS입니다.

알아서 최신 버전

새 버전의 서명을 확인한 뒤, 쓰지 않을 때 조용히 업데이트합니다.

How it works

1분이면 연결됩니다

계정 가입도, 외부 서버도 없습니다. 내 컴퓨터끼리 바로 연결합니다.

공유 켜기

접속받을 컴퓨터에서 RemoteDesk를 열고 비밀번호를 정한 뒤 공유 시작을 누릅니다.

주소 넣기

다른 컴퓨터에서 RemoteDesk를 열고 화면에 나온 주소와 비밀번호를 넣어 연결합니다.

FAQ

자주 묻는 질문

정말 무료인가요?

네. 계정 가입이나 구독 없이 씁니다.

중간에 다른 서버를 거치나요?

아니요. 두 컴퓨터가 직접 연결되고, 모든 내용은 비밀번호에서 만든 키로 암호화됩니다.

아이폰에 앱을 깔아야 하나요?

아니요. Safari로 접속합니다. 처음 한 번 접속받을 컴퓨터가 만든 인증서를 설치하면 이후에는 주소만 열면 됩니다.

노트북을 덮어도 접속되나요?

공유 중에는 잠자기를 막아 둡니다. 다만 덮개를 닫았을 때 잠드는지는 기기와 전원 설정에 따라 다르니, 전원에 연결해 두는 것을 권합니다.

업데이트는 어떻게 하나요?

앱이 6시간마다 새 버전을 확인하고, 서명을 검증한 뒤 쓰지 않을 때 설치합니다. 설정에서 끌 수 있습니다.
