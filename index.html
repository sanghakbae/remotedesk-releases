RemoteDesk

맥과 윈도우를 서로 오가는 원격 데스크톱입니다. 아이폰 Safari에서도 앱 설치 없이 접속합니다.

기능

맥 ↔ 윈도우 양방향

맥에서 윈도우로, 윈도우에서 맥으로, 같은 운영체제끼리도 접속합니다. 단축키는 상대 운영체제에 맞게 바꿔 보냅니다.

아이폰·태블릿 웹 접속

Safari로 주소만 열면 됩니다. 탭은 클릭, 길게 누르면 오른쪽 클릭, 두 손가락으로 확대·이동합니다.

최대 60fps

macOS는 ScreenCaptureKit으로 화면을 잡아 바뀐 부분만 보냅니다. 실제 속도는 네트워크에 따라 다릅니다.

해상도 자동 맞춤

원격 컴퓨터의 해상도에 맞춰 창 크기를 정하고, 화질 단계(낮음·보통·높음·최고)를 고를 수 있습니다.

클립보드 공유

텍스트, 이미지, 파일을 복사해 반대편에 붙여 넣습니다.

한글 입력

한/영 전환과 한글 입력을 지원합니다. 아이폰 키보드의 한글 조합도 그대로 전달됩니다.

잠자기 방지

공유하는 동안 컴퓨터가 잠들지 않게 해 접속이 끊기지 않습니다.

암호화

비밀번호로 키를 만들어 모든 화면과 입력을 AES-GCM으로 암호화합니다. 웹 접속은 HTTPS를 씁니다.

서명된 자동 업데이트

새 버전을 받아 서명을 확인한 뒤, 사용 중이 아닐 때 설치합니다. 설정에서 끌 수 있습니다.

시작하기

1. 접속받을 컴퓨터

  1. RemoteDesk를 설치하고 엽니다.
  2. 비밀번호를 정하고 공유 시작을 누릅니다.
  3. 화면에 나온 주소를 확인합니다.

2. 접속하는 컴퓨터

  1. RemoteDesk를 열고 주소와 비밀번호를 넣습니다.
  2. 연결을 누릅니다.

3. 아이폰에서

  1. Safari로 https://주소:47801 을 엽니다.
  2. 처음 한 번은 화면 안내대로 인증서를 설치합니다.
  3. 비밀번호를 넣고 접속합니다.

설치 안내

macOS

  • macOS 12 이상. Apple 실리콘과 Intel 맥 모두 지원합니다.
  • 처음 열 때 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 누릅니다.
  • 접속받을 맥은 화면 기록과 손쉬운 사용 권한을 켜야 합니다.

Windows

  • Windows 10, 11 (64비트).
  • SmartScreen 경고가 나오면 추가 정보 → 실행을 누릅니다.
  • 방화벽 허용 창이 나오면 허용합니다.

외부에서 접속하려면 접속받을 컴퓨터의 공유기에서 포트 47800(앱)과 47801(웹)을 열어 두어야 합니다. 같은 네트워크 안에서는 따로 설정할 것이 없습니다.
